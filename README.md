# سابر (Saber) هو أداة بحث صاروخية لنظام Windows. سُميت بهذا الاسم لأنها "تغوص" في أعماق المجلدات لتجلب ملفاتك بدقة 100% وبسرعة فائقة، بدلاً من انتظار بحث الويندوز التقليدي الممل.
تجاوز بطء بحث الويندوز التقليدي مع واجهة عصرية وسجل بحث ذكي!

## 🚀 المميزات (Features)
* **سرعة صاروخية:** خوارزمية بحث محسنة تتجاهل مجلدات النظام الثقيلة (مثل Windows و Program Files) لضمان أسرع نتيجة ممكنة.
* **دقة 100%:** يبحث عن التطابق التام لاسم الملف لتجنب النتائج العشوائية المزعجة.
* **سجل ذكي (History):** يحفظ الملفات التي قمت بفتحها للوصول السريع لها لاحقاً، مع إمكانية مسح السجل بضغطة زر.
* **واجهة عصرية:** تصميم Dark Mode مريح للعين مبني باستخدام مكتبة `PySide6` المتقدمة.
* **نسخة محمولة (Standalone):** لا يحتاج إلى تثبيت، فقط قم بتشغيل ملف الـ `.exe` وابدأ السبر!

## 🛠️ كيفية الاستخدام (Usage)
1. قم بتحميل أحدث إصدار من قسم [Releases](رابط_الريليز_هنا).
2. تأكد من وجود صورة البانر `bannar.png` بجانب البرنامج (إذا كنت تستخدم نسخة المجلد).
3. افتح `Saber.exe`، اكتب اسم الملف، واضغط **بحث**.
4. اضغط مرتين على أي نتيجة لفتح موقع الملف مباشرة في متصفح الملفات.

## 💻 التقنيات المستخدمة (Tech Stack)
* **اللغة:** Python 3
* **الواجهة الرسومية:** PySide6 (Qt for Python)
* **المعالجة المتعددة:** Threading (لضمان استقرار الواجهة أثناء البحث)
